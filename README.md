# suraj-kgp-ub.vercel.app

Personal site for Suraj Sah. Next.js (App Router) + [motion](https://motion.dev).

- Content lives in `src/content.ts` — edit text there, not in components.
- `npm run dev` for local development, `npm run build` to verify before pushing.
- Pushes to `main` deploy to production on Vercel.
